# Application Screenshots Guide

This directory is designated for high-resolution visual previews of the Brightloop Subscription Management System for hackathon review and documentation showcase.

### Recommended Screen Captures

| Filename | View | Path / Route | Focus Elements |
|---|---|---|---|
| `01-login-screen.png` | Authentication Portal | `/login` | Brutalist branding, credentials card, role quick-access notes |
| `02-admin-dashboard.png` | Executive Finance Dashboard | `/` | Revenue metrics, ARR/MRR run-rates, billing trend charts, recent ledger |
| `03-customer-management.png` | Customer Directory | `/customers` | Enterprise accounts table, financial summary chips, customer 360 modal |
| `04-products-variants.png` | Product & Variant Catalog | `/products` | Software & service items, price points (₹), Odoo edition variant config |
| `05-subscription-plans.png` | Subscription Plans Tiering | `/plans` | Billing frequencies, grace period controls, pause/cancellation governance |
| `06-quotations-proposals.png` | Quotation & Contract Builder | `/quotations` | Multi-line item proposal builder, automated discounts, tax rules |
| `07-subscriptions-lifecycle.png` | Subscription Lifecycle | `/subscriptions` | Recurring contracts, active/paused status, next billing cycle evaluation |
| `08-invoices-ledger.png` | Invoices & Financial Ledger | `/invoices` | Billed cycles, balance tracking (₹), official PDF downloads, payment trigger |
| `09-payment-recording.png` | Payment Processing Modal | `/invoices` & `/payments` | Partial/full payment settlement modal, transaction records |
| `10-customer-portal.png` | Customer Self-Service Portal | `/portal` | Customer-facing subscription overview, invoice history, proposal sign-off |

Place capture files in this folder to have them display in the repository documentation.
